# 📚 StudyMeta AI

StudyMeta AI is a free PDF-based study assistant built using Python and Streamlit.

It helps students read study material, create practice questions, take quizzes, and track quiz performance.

## ✨ Features

- 📄 Upload PDF study material
- 📖 Extract PDF text
- 🔎 Search inside PDF
- 📚 Generate quick study summary
- ❓ Practice questions
- 🎯 PDF-based quiz
- ✅ Automatic answer checking
- 📊 Score and percentage
- 📈 Quiz score history
- 💾 Download quiz history as CSV
- 📥 Download study summary
- 🎚️ Easy, Medium and Hard difficulty levels

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Pandas
- Git
- GitHub
